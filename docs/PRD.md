# PRD — Claude Code 한글 입력

상태: 0.1 공개. 구현 세부·실측 로그는 [SPEC.md](SPEC.md).

## 문제

Claude Code 프롬프트는 OS 한글 IME가 없거나 먹지 않는 환경이 있다. 원격 터미널, 샌드박스, IME가 프롬프트에 전달되지 않는 경우가 그렇다. 그 상태에서 두벌식과 세벌식을 치고, 같은 줄에 영어·숫자·기호도 넣어야 한다.

## 사용자

Claude Code 프롬프트에 한글 문장을 쓰는 사람. 레이아웃은 두벌식, 세벌식 390, 세벌식 최종 중 하나다.

## 목표

1. OS IME 없이 프롬프트 입력창에서 세 레이아웃을 조합한다.
2. `/hangul` 로 켜고 끄고, 레이아웃을 고른다. 켠 뒤에도 `off` 를 영어로 칠 수 있다.
3. 한글 단어는 한글로, 영어 단어·숫자 단어·문장부호는 친 문자로 남긴다.
4. 조합 코어는 Claude Code API와 분리된 순수 모듈이다.

## 비목표

- 한자 변환, 후보 창, 사전, 자동완성.
- 세벌식 390·최종 외의 자판, 옛한글.
- OS 전역 IME, Claude Code 밖의 앱.
- 한영 키·Caps Lock·Globe 를 토글에 쓰는 것. 전환은 `/hangul` 이다.

## 사용

| 입력 | 결과 |
|---|---|
| `/hangul` | 켜짐과 꺼짐을 바꾼다 |
| `/hangul on` / `off` | 켠다 / 끈다 |
| `/hangul 2` / `390` / `final` | 그 레이아웃으로 켠다 |

환경변수 `HANGUL_LAYOUT` 으로 시작 레이아웃을 정한다. 기본은 두벌식.
`HANGUL_SEBEOL_ORDER=strict` 이면 세벌식에서 초·중·종 역순은 확정한다. 기본은 한 음절 안에서 순서 무관이다.

상태줄 문자열은 `한 두벌식`, `한 세벌식 390`, `한 세벌식 최종` 이다. 꺼지면 지운다.

## 입력 규칙

### 한글

- 두벌식은 자음이 초성과 종성을 겸한다. 받침 뒤에서 모음이 오면 도깨비불로 다음 음절 초성이 된다. 겹받침은 뒤 자모만 넘어간다. 시프트로 넣은 ㄲ·ㅆ 받침은 한 덩어리로 넘어간다.
- 세벌식은 키가 초성·중성·종성으로 고정되고 도깨비불이 없다.
- 초성과 중성이 모인 음절만 한글로 낸다.
- 백스페이스는 아직 끝나지 않은 단어의 마지막 키를 지우고 다시 조합한다.

### 영어, 숫자, 특수문자

단어는 공백이나 기호 앞까지다.

| 단어 | 결과 |
|---|---|
| 완성 음절만 | 한글. `gksrmf` → `한글` |
| 음절이 아닌 조각이 확정됨 | 친 키. 세벌식 `hello` → `hello` (`녀llo` 가 아님) |
| 끝날 때 한글과 낱자가 섞임 | 친 키. `hell?` → `hell?` |
| 숫자만 | 숫자. `390`, `123`, `3.14` |
| 표에 없는 기호 | 친 문자. `?` `,` `!` |

한 음절로 끝나는 영어는 한글으로 남는다. 두벌식 `to` 는 `새`. 이건 사전 없이 가르지 않는다.

세벌식 숫자 키가 이미 열린 음절의 자모로 붙으면 그 음절은 한글이다. 숫자만 모인 단어만 숫자로 고정한다.

세벌식 기호 치환은 기본으로 한다. 390 `<` 는 `2`, `J` 는 `4` 다. 세벌식 숫자는 시프트 자리에만 있어 치환하지 않으면 칠 수 없다(2026-10-05 실사용에서 확인). 친 문자를 원하면 코드 옵션 `passthroughLiterals: true` 다. `/hangul` 인자로는 바꾸지 않는다.

`/hangul` 을 치는 동안과 그 인자는 조합하지 않는다. 다른 슬래시 명령은 이름 뒤 공백부터 다시 한글이다. 문장 중간의 `/` 는 세벌식에서 ㅗ다.

붙여넣기는 변환하지 않는다.

## 완료 기준

- `claude plugin test .` 통과.
- 두벌식 `gksrmf`, 세벌식 390·최종 `mfskgw` 가 `한글`.
- 세벌식 `hello?`, `how are you`, `390` 이 친 문자 그대로.
- `/hangul off` 와 `/hangul 390` 이 영어 그대로.
- `tsc -p .` 오류 0.

## 확인된 것과 아닌 것

Claude Code 2.1.289 샌드박스에서 플러그인 로드, `/hangul`, 두벌식·세벌식 `한글`, 붙여넣기, Enter(`prompt.submit`), vim insert 를 봤다.

아직 아닌 것: 한영 키, Caps Lock 키, Globe, 조합 밑줄이 화면에 그려지는지, 리로드 후 상태줄, macOS·Windows IME 와의 대조, KS X 5002·한글문화원 원문 도표.
